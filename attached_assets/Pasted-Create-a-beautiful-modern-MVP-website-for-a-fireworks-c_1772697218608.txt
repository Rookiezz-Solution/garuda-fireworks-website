Create a beautiful, modern MVP website for a fireworks company called **Garuda Fireworks**.

The goal is to create a **customer-friendly fireworks catalogue website** where users can browse products and send inquiries via WhatsApp. This is NOT an ecommerce checkout system.

Use the following technologies:

* React (Vite)
* Tailwind CSS
* React Router
* Local JSON data for products

The website must look **modern, festive, and visually impressive** with smooth animations and mobile responsiveness.
