Extend the existing React MVP website for **Garuda Fireworks** by adding a simple e-commerce style cart and checkout system. This is NOT a real payment gateway. Instead, the order will be sent as a formatted WhatsApp message to the admin.

Admin WhatsApp number:
8838497929

The goal is to allow users to add fireworks to a cart, review their order, enter their details, and send the order request to WhatsApp.

Do NOT rebuild the project. Extend the current structure.

---

FEATURES TO ADD

1. CART SYSTEM

Create a cart system using React Context API.

Users must be able to:

* Add product to cart
* Increase quantity
* Decrease quantity
* Remove product
* View cart items
* See total price

Store cart items in localStorage so cart persists after refresh.

---

Button:

* Product is added to cart
